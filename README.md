# Flappy Bird Clone 🐦

A simple game inspired by **Flappy Bird**, developed using **Unity and C#** as a personal learning project.

The goal of this project is to practice game development fundamentals, explore Unity's features, and improve my C# programming skills.

## 🎮 Gameplay

Control a bird and navigate through obstacles without colliding with them. Each successfully passed obstacle increases your score.

## 🛠️ Technologies

- **Unity** – Game engine
- **C#** – Programming language

## 📚 Learning Objectives

- Understand Unity's 2D physics system
- Implement player movement and input handling
- Practice collision detection
- Create an obstacle spawning system
- Implement a scoring system
- Manage basic game states (start, game over, restart)
- Improve code organization and C# skills

## 🚀 Getting Started

1. Clone this repository.
2. Open **Unity Hub**.
3. Add the cloned project to Unity Hub.
4. Open the project using its compatible Unity version.
5. Open the main scene and press **Play**.
